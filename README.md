# 📡 NMLAlert System - Network Monitoring & LINE Alert System

ระบบตรวจสอบสถานะเครือข่ายระดับพรีเมียม (NOC Premium Dashboard) ที่มาพร้อมระบบตรวจสอบความพร้อมของอุปกรณ์ในเครือข่ายแบบเรียลไทม์ การสแกนค้นหาอุปกรณ์ในวง LAN อัตโนมัติ และการแจ้งเตือนสัญญาณไฟแดง/เขียวพร้อม**ระบุตำแหน่งของอุปกรณ์** ส่งตรงเข้าแอปพลิเคชัน LINE ทันทีเมื่อเกิดความขัดข้อง

## 🎨 การออกแบบและการตกแต่งระดับพรีเมียม (Premium UX/UI Design)
* **สไตล์กระจกเงาเงามิติ (Premium Glassmorphism)**: การจัดวางเลย์เอาต์หน้าบ้านที่เน้นความโปร่งใส คลาสสิก หรูหรา สบายตา และมีมิติด้านพื้นที่ (Enhanced Spacing) ไม่ติดขัดกัน
* **การสนับสนุนชุดธีมสี (Theme Support)**:
  * **Deep Space (Default)**: ธีมมืดสุขุม ลึกลับ มีชีวิตชีวาด้วยแถบส้ม-ฟ้านีออน
  * **Light Aurora**: ธีมสว่างสไตล์มินิมอล ช่วยลดความเครียดสายตาเมื่อต้องใช้งานในเวลากลางวันหรือห้องที่สว่างมาก
* **Slide-out Details Drawer**: เมื่อกดเลือกอุปกรณ์ที่สนใจ จะมีแผงเมนูด้านข้างสไลด์ออกมาอย่างนุ่มนวล พร้อมแสดงสถิติ Telemetry เสมือนจริง เช่น อัตราการใช้งาน CPU, RAM และแบนด์วิดท์อัปโหลด/ดาวน์โหลด

| :--- | :--- | :--- |
| **Frontend (หน้าบ้าน)** | HTML5 / Vanilla CSS / ES6+ JavaScript | หน้าเดี่ยว (Single Page Application) เขียนสดทั้งหมดโดยไร้เฟรมเวิร์ก เพื่อความเร็วสูงสุดและน้ำหนักเบา |

## 🛠️ ฟีเจอร์หลักของระบบ (Core Features)

1. **ระบบล็อกอินรักษาความปลอดภัย (Secure Authentication Guard)**
   - ป้องกันสิทธิ์การเข้าถึงหน้าแดชบอร์ด โดยมีระบบเช็คประวัติ Session ผ่าน LocalStorage (ปัดผู้ใช้งานที่ไม่ได้ล็อกอินกลับไปที่หน้าล็อกอินโดยอัตโนมัติ)
   - สิทธิ์ผู้ใช้เริ่มต้น:
     - แอดมิน: `admin` / รหัสผ่าน: `admin` (สิทธิ์: Admin)
     - โอเปอเรเตอร์: `operator01` / รหัสผ่าน: `operator01` (เก็บรหัสผ่านใน MySQL ด้วยการแฮชแบบปลอดภัย)
2. **แดชบอร์ดตรวจสอบเรียลไทม์ (Real-time Telemetry Dashboard)**
   - แสดงตัวเลขรวม สรุปยอดออนไลน์ ออฟไลน์ และตัวเตือนหน่วงสูง (Warning)
   - กราฟประวัติ Telemetry แบบเส้นโค้ง Bézier พร้อมฟิลเตอร์ตัวกรองประวัติในหน้า SysLogs
3. **ระบบตรวจสอบแบบทีละนาที (Background Ping Daemon)**
   - หลังบ้านจะทำการปิงอุปกรณ์ทุก ๆ 60 วินาทีตามรายการใน MySQL หากเครื่องมีอาการตอบสนองช้าเกินกว่า 45ms จะขึ้นเตือนสีเหลือง (Warning) และหากไม่ตอบสนองเลยจะเปลี่ยนเป็นสีแดง (Offline) และทำการแจ้งเตือนเข้า LINE ทันที
4. **ตัวค้นหาและเชื่อมโยงอุปกรณ์อัจฉริยะ (IP Subnet Scanner)**
   - สแกนหาช่วงไอพี Class C Subnet (เช่น `192.168.1.1` - `254`) แบบคู่ขนานอย่างรวดเร็ว
   - แสดงผล IP Address, MAC Address และดึงชื่อเครื่อง Hostname จาก Reverse DNS อัตโนมัติ พร้อมมีปุ่มคลิกด่วน **"+ Add Device"** เพื่อแอดโหนดใหม่เข้าฐานข้อมูลได้ในคลิกเดียว

## 🚀 ขั้นตอนการติดตั้งและเปิดใช้งาน (Installation & Run Guide)

### 1. การเตรียมระบบฐานข้อมูล (MySQL)
1. เปิดใช้งานระบบ **MySQL** บน **XAMPP Control Panel** (หรือระบบเซิร์ฟเวอร์ MySQL ของคุณ)
2. เข้าไปที่ **phpMyAdmin** หรือโปรแกรมจัดการฐานข้อมูลของคุณ
3. สร้าง Database ใหม่ชื่อว่า `netwatch_noc`
4. นำเข้า (Import) ไฟล์สคริปต์โครงสร้างตารางข้อมูลจากไฟล์ **[schema.sql](file:///d:/Intern%20project/schema.sql)** เพื่อสร้างตารางและใส่ชุดข้อมูลทดสอบเบื้องต้นลงฐานข้อมูล

### 2. ตั้งค่าไฟล์สภาพแวดล้อม (.env)
สร้างไฟล์ชื่อ `.env` ไว้ที่โฟลเดอร์ราก (Root Directory) ของโครงการ และระบุข้อมูลการเชื่อมต่อดังนี้:

```env
PORT=3000
DB_HOST=127.0.0.1
DB_USER=root
DB_PASSWORD=
DB_NAME=netwatch_noc
LINE_NOTIFY_TOKEN=YOUR_LINE_MESSAGING_API_TOKEN_HERE
```
*(หมายเหตุ: ระบบจะทำการตรวจความยาวโทเค็นอัตโนมัติ หากนำโทเค็น LINE Messaging API Channel Access Token มาใส่จะทำส่งรูปแบบ Broadcast สมบูรณ์แบบทันที)*

### 3. การติดตั้ง Dependencies และเริ่มระบบ
เปิด Command Prompt / PowerShell ในโฟลเดอร์โครงการ และทำตามขั้นตอนต่อไปนี้:

1. **ติดตั้งไลบรารีที่เกี่ยวข้อง**:
   ```bash
   npm install
   ```
2. **รันระบบในโหมดทำงาน**:
   ```bash
   npm start
   ```
3. เมื่อเปิดใช้งานเรียบร้อยจะปรากฏข้อความยืนยันสถานะ:
   ```text
   ✨ NMLAlert System backend is active on http://localhost:3000
   🚀 MySQL database connected successfully!
   ⏱️ Background Ping Daemon initialized. Checking nodes every 60s...
   ```

4. เปิดเว็บบราวเซอร์และเข้าไปที่: **`http://localhost:3000`** เพื่อเข้าใช้งานระบบได้ทันที!
